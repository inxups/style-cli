## 固定语料与本地编码

[固定语料](../../testdata/manual/token-calibration-40.json) 为 20 条英文、20 条中文工程规则，沿用原正文及 SHA256。重新构建的生产 STYLE SHA256 为 `32aef36dcb67d8cd0c57e123016094e1f82e5cce8adca37a9b6ae56c990cf81d`，与之前最终生产构建一致；估算来自真实 `style plan --harness codex --json`，不在脚本中复制估算公式。

使用 Python 3.14.7、临时 venv 中的 `tiktoken==0.12.0`，显式选择 `o200k_base` / `cl100k_base`，不假设它们对应当前任意特定模型。逐条记录纯正文计数，以及原固定前缀加正文减去前缀的本地文本增量；本语料两种口径逐条相等。消息封装、工具、隐藏指令、缓存和账单均不在计数范围。

| 编码／语言 | 条数 | STYLE 估算合计 | 本地纯正文合计 | 逐条平均绝对相对偏差 |
|---|---:|---:|---:|---:|
| o200k_base／全部 | 40 | 1,205 | 816 | 49.8051% |
| o200k_base／英文 | 20 | 626 | 377 | 66.6901% |
| o200k_base／中文 | 20 | 579 | 439 | 32.9201% |
| cl100k_base／全部 | 40 | 1,205 | 972 | 36.5474% |
| cl100k_base／英文 | 20 | 626 | 380 | 65.3188% |
| cl100k_base／中文 | 20 | 579 | 592 | 7.7761% |

平均绝对相对偏差为逐条 `abs(STYLE估算 − 本地参考) / 本地参考` 的算术平均，区别于合计数量的偏差。完整逐条结果、语言分组、平均有符号偏差、最大偏差、语料/采集器/二进制摘要和编码表 token-ID/字节映射摘要见 [本地编码 JSON](M2-ALT-01-LOCAL-TOKENS-2026-10-17.json)。`completed` 仅表示数据采集完整，没有准确性通过阈值。

结果显示当前系数对这份语料的英文倾向高估；`cl100k_base` 下有中文条目低估。不能把估算描述为严格上界，不能用本结果推断 Claude 分词或某个 OpenAI 模型误差，也没有据此调整产品预算和默认值。

[订阅 usage JSON](M2-ALT-01-CLAUDE-USAGE-2026-10-17.json) 只含来源摘要、会话身份、模型和四种 token usage。每个响应身份只保留最后快照；总输入为 `input_tokens + cache_creation_input_tokens + cache_read_input_tokens`，缓存 TTL 子项不重复相加。原始 prompt、工具正文、鉴权与登录配置不导出。

这六个会话的样式、工具、指令、缓存状态不同，不是受控 A/B。安装／卸载会话的 usage 不能相减作为单条规则成本；不声称逐规则归因、实际账单、重试或独立子 agent 全覆盖。没有为补充报告再次请求模型。
